Tic-Tac-Toe

A two-player Tic-Tac-Toe game developed using C# and Windows Forms.

Overview

A simple interactive desktop game where two players take turns placing their marks on a 3×3 game board.

Features

- Two-player gameplay
- Player turn management
- Win detection
- Draw detection
- Game reset
- Interactive Windows Forms interface

Technologies

- C#
- .NET Framework
- Windows Forms (WinForms)

Purpose

This project was developed to practice:

- C# programming
- Event-driven programming
- Game-state management
- Conditional logic
- User interface development
- Problem solving
